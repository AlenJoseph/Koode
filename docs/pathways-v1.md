# Koode pathways v1 (research grounding)

Working catalogue for product pathways. Landing copy should follow the **pathway names** below.

**Landing rule:** do **not** paste WHO / UNICEF / OECD / UN logos or “aligned with SDG …” wallpaper on the marketing site. That reads as borrowed credibility. Keep citations here for builders, grant notes, and due diligence. The public page sells the product in plain language.

## What a “pathway” means here

UNESCO describes learning pathways as how learners **sequence** learning and skill development toward competence, often across formal and informal settings ([UNESCO UIL flexible pathways](https://lifelonglearning-toolkit.uil.unesco.org/en/node/214)).  
Koode pathways are **themed competence tracks**: a student picks a world, then loops through challenges → practice → build → reflect.

## Frameworks we draw from

| Source | What we take |
| --- | --- |
| **WHO life skills** (school programmes) | Ten core skills: self-awareness, empathy, critical/creative thinking, decision-making, problem-solving, communication, relationships, coping with stress/emotion. |
| **UNICEF transferable skills** | Outcomes: lifelong learning, employment/enterprise, personal empowerment, **active citizenship**. Multiple pathways (school, community, work). |
| **UNICEF India Comprehensive Life Skills** | Holistic life skills + livelihood distinction; local adaptation. |
| **OECD Learning Compass 2030** | Transformative competencies: **create new value**, **reconcile tensions**, **take responsibility**. Learning cycle: **Anticipation → Action → Reflection**. |
| **UNESCO-IBE competences** | Lifelong learning, self-agency, interacting with others/world, tools & resources, transdisciplinarity, multi-literacies (incl. **health** and **financial** literacy). |
| **UN SDGs** | Shared impact language (esp. 3, 4, 8, 10, 11, 12, 13, 15). Koode is not a UN programme. |

## v1 pathway set (recommended)

Concrete missions students recognise, mapped to the frameworks above.

| Pathway | Student-facing promise | Primary skills | SDG anchors |
| --- | --- | --- | --- |
| **Know yourself** | Notice feelings, strengths, and stress; choose healthier responses | Self-awareness, coping (WHO) | 3 |
| **Think it through** | Decide under uncertainty; solve unfamiliar problems | Critical/creative thinking, decision-making, problem-solving (WHO) | 4 |
| **Speak & listen** | Explain clearly, listen with empathy, handle conflict | Communication, empathy, relationships (WHO) | 4, 16 |
| **Body & care** | Food sense, movement basics, first aid calm | Health literacy (UNESCO), care skills | 2, 3 |
| **Money sense** | Budgets, fair trade, saving, spotting bad deals | Financial literacy (UNESCO-IBE) | 1, 8 |
| **Civic life** | Clean shared spaces, neighbour care, local voice | Active citizenship (UNICEF) | 11, 16 |
| **Living world** | Wildlife, habitats, climate-aware local action | Environmental custodianship (UNESCO-IBE) | 13, 15 |
| **Make & serve** | Tiny enterprise, teach a peer, build a useful tool (software only when it helps) | Create new value + responsibility (OECD) | 8, 9 |

## Product loop (keep aligned)

Prefer the OECD cycle in product language:

1. **Anticipate** (discover interest / plan a mission)  
2. **Act** (challenge + practise + build)  
3. **Reflect** (evidence, next goal)

Do **not** sell coding as the product. Software sits inside **Make & serve** when a real problem needs a tool (README farming example spirit: investigate → practise → build → explain).

## Out of scope for v1 pathway marketing

- Investor / fundraising pitch blocks on the public landing  
- Permanent ability labels or employability scores (see product principles)  
- Claiming UN endorsement
